## 当前范围

- 只收录已确认的 2027 届正式校招研究岗
- 当前岗位库：31 个正式研究岗，分布在 19 家有岗公司
- 公司库：62 家重点公司，当前 51 家 27 届正式校招已开；默认展示 12 家，支持展开全部、搜索和状态筛选；公司卡片可直接筛选岗位
- 行业筛选：互联网、电商、智能硬件、汽车、游戏等
- 类型筛选：战略/策略向、交互/设计向、体验管理向、不确定（官网未提供足够信息时使用）
- 详情页提供官方链接、官网公开岗位内容、岗位分析和投递建议
- 可在列表直接记录投递状态，并在详情页填写计划投递日期、实际投递日期和备注
- 个人记录保存在当前浏览器的 `localStorage`，不会写入访问统计，也不会跨设备同步
- 蔚来“安全体验研发工程师”不纳入本岗位库
- 公司名单是重点公司观察池，不是全量公司榜单；选入依据为求职关注度、行业覆盖、研究相关性与公开校招入口，并保留已开/专项/待确认对照组

公司状态与岗位数量为 2026-09-09 的公开渠道核验快照；“尚未确认正式批”不等于公司不会开放，投递前请回到公司官方招聘页复核。

岗位信息会变化，投递前请点击详情页的官方链接复核。
